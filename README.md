## 🚀 Como colocar o site no ar (2 minutos)

O site é estático — qualquer hospedagem gratuita serve:

1. **GitHub Pages (recomendado, grátis):** no repositório, abra *Settings → Pages → Source: branch `main`, pasta `/ (root)` → Save*. O site entra no ar em `https://superaplicativos.github.io/MarceloDercatshoff/` em poucos minutos.
2. **Domínio próprio (opcional):** contrate um domínio (ex.: `drmarcelodercatshoff.com.br`), aponte para o GitHub Pages (ou Netlify/Vercel, basta arrastar a pasta) e atualize a URL canônica no `index.html`, `sitemap.xml` e `robots.txt`.
